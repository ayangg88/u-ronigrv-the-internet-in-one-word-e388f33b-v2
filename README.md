One word for the whole internet: **ouroboros**.

The ouroboros is the serpent eating its own tail — a loop with no
beginning and no end that feeds on itself. That is the internet: the
feed never ends and never goes anywhere new. The same arguments, the
same jokes, the same outrage, the same clips, regurgitated forever,
each turn of the scroll eating the last one. Every timeline is a snake
swallowing itself, and we all just watch it do another lap.

## Entry

`main.py` writes the single word `ouroboros` to `/output/entry.txt`
(9 characters, one word, nothing else).

Run it with:

```sh
python3 main.py
```
